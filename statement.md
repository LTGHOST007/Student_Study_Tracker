Project Statement

 Project Title

Student Study Tracker

 Problem Statement

Students study various subjects and topics daily. Sometimes, it is hard to track how long one studied each subject.

Student Study Tracker helps record and monitor the learning process simply.

Scope

The project will track the following:

- Subject

- Topic

- Study time

The project will be a simple console application with no online accounts, payments, and cloud storage.

Target Users

College students will be the target users of the application.

 Main Features

Student Study Tracker will have the following features:

1. Add a study session

2. View study sessions

3. Delete a study session

4. Calculate the total time spent studying

5. Calculate the time spent studying each subject

6. Store data in a Json file

7. Validate the input data
